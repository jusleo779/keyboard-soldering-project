# Keyboard Design

My original design was created to have PCB supports, slots for slip pads, and holes for screwholes. There were many issues with design related to constraints and measurements. Many of my constraints weren't set, which made the 3d printed model messed up and an inaccurate representation of the case I meant to create. The second and final iteration updated and fixed those issues while adding extra PCB support and a hole for the microcontroller to prevent further damage to it.
